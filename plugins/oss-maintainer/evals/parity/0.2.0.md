## Deterministic and structural checks

- Regression tests cover strict/repeated command parsing, execution identity and revalidation,
  dependency-specific evidence invalidation, atomic artifact registration, typed permissions,
  limits/expiry, changed policies, delivery closure, legacy records and optional retro.
- Instruction migration tests cover root/nested scope, preserved content, updated references,
  idempotence, divergent canonical content, stale plans, cycles and symlinks.
- Profile tests cover direct/PR/repository delivery, custom triage, independent batch policies
  and contradictory mandatory/nonblocking gates.
- Claude marketplace/plugin/skill/agent validation passed. Agent Smith validation passed with
  the existing shared-frontmatter warnings and accepted Codex smoke-agent adapter gap.
